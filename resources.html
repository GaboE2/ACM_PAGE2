CS Roadmap

El Mapa de Ruta de Ciencias de la Computación de ACM UCSP es una guía visual y estructurada que cubre los temas, tecnologías y habilidades esenciales para tu formación como profesional de la computación. Desde fundamentos hasta especialidades avanzadas.

Carátula UCSP

Plantillas oficiales de carátula para trabajos académicos en la Escuela Profesional de Ciencia de la Computación de la UCSP. Disponibles en formato LaTeX (Overleaf compatible) y Microsoft Word. Cumplen con los lineamientos de presentación del departamento.

Descarga la plantilla

Elige el formato que mejor se adapte a tu flujo de trabajo. La plantilla LaTeX es ideal para documentos técnicos y papers; la versión Word es recomendada para reportes y trabajos de curso generales.

Recuerda que no necesitas instalar LaTeX localmente; puedes usar Overleaf directamente en tu navegador de forma gratuita.

Descargar Plantilla LaTeX (.zip) Abrir en Overleaf Generador Oficial UCSP (online) Descargar Plantilla Word (.docx)

¿Cómo usar la plantilla LaTeX?

  1. Descarga el archivo caratula_ucsp_latex.zip y descomprímelo.
  2. Sube el archivo .tex a Overleaf o compílalo con TeXLive / MiKTeX.
  3. Edita el título, autores, docente y fecha directamente en el archivo.
  4. Compila con pdflatex caratula_ucsp.tex o usa el botón "Recompilar" en Overleaf.
  5. ¡Listo! Obtén tu PDF con el formato oficial UCSP.

Otras Guías

Recursos adicionales curados por los miembros del capítulo para apoyar tu aprendizaje autónomo, preparación para entrevistas técnicas y desarrollo profesional.

⚡ Guía de Programación Competitiva

Compendio de recursos para prepararte para el ICPC y concursos nacionales. Incluye lista de temas esenciales, libros recomendados (Competitive Programmer's Handbook, KACTL), plataformas de práctica (Codeforces, AtCoder, SPOJ) y estrategias de resolución de problemas.

  • Estructuras de datos: Segment Tree, BIT, DSU, Treap
  • Algoritmos de grafos: Dijkstra, Bellman-Ford, Flujo máximo, LCA
  • Programación dinámica: Bitmask DP, DP en árboles, DP convexa
  • Matemáticas: Teoría de números, combinatoria, geometría computacional
Practicar en Codeforces

📄 Preparación de CV y Entrevistas Técnicas

Aprende a crear un CV de una página que destaque en el sector tech. Incluye plantillas, consejos para el formato ATS-friendly, y una guía de preparación para entrevistas técnicas con los patrones de problemas más frecuentes (LeetCode 150, NeetCode, Blind 75).

  • CV tips: Formato LaTeX, métricas de impacto, sección de proyectos
  • LeetCode patterns: Two Pointers, Sliding Window, Binary Search, Backtracking
  • Behavioral: Método STAR para respuestas de comportamiento
  • System Design: Escalabilidad, bases de datos, caché y microservicios
Explorar NeetCode.io

🌿 Git & GitHub para Proyectos Académicos

Desde los primeros pasos con Git hasta flujos de trabajo avanzados (GitFlow, Pull Requests, GitHub Actions). Aprende a versionar tus proyectos académicos, colaborar en equipo y publicar tu portafolio en GitHub Pages.

  • Básico: git init, add, commit, push, pull
  • Colaboración: Branches, merge, rebase, resolución de conflictos
  • GitHub: Issues, PRs, Actions para CI/CD, GitHub Pages
  • Buenas prácticas: .gitignore, mensajes de commit semánticos, READMEs
